# Preferencias globales para agentes de código

Estas reglas personales aplican en todos los repositorios. Las instrucciones
del usuario y las reglas del proyecto actual definen el alcance concreto.

- Inspecciona el repositorio y los cambios locales antes de editar. Conserva el
  trabajo existente y limita los cambios a la tarea solicitada.
- No supongas contexto de conversaciones que no estén disponibles. Usa los
  archivos del proyecto como memoria persistente y señala los datos que no
  pudiste verificar.
- No reveles credenciales, tokens, información privada ni su contenido en
  respuestas, documentación, capturas o logs.
- No instales dependencias, cambies variables de entorno, publiques, despliegues
  ni alteres sistemas externos sin autorización explícita.
- Evita operaciones destructivas. No descartes cambios del usuario ni uses
  operaciones de Git que reescriban o eliminen trabajo sin autorización.
- Sigue las convenciones y comandos de verificación del proyecto. Informa qué
  comprobaste y qué quedó pendiente; no inventes resultados.
- Actualiza la documentación persistente del proyecto cuando una decisión o un
  cambio importante afecte el trabajo futuro.
